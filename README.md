# 모임 금액정산 계산기

모임의 계산서와 차수별 참석자·술값을 반영해 각자 낼 금액을 정산하는 계산기입니다. 회비를 먼저 걷은 경우에는 선입금 후 정산 방식도 사용할 수 있습니다.

처음 열거나 초기화하면 **계산서로 바로 정산**으로 시작합니다. 저장된 모임이 있으면 마지막에 사용한 방식을 이어서 열며, 화면 위에서 다른 방식으로 전환할 수 있습니다.

- **계산서로 바로 정산:** 참석자 닉네임과 실제 계산서 금액만 입력해 각자 낼 금액을 계산합니다.
- **선입금 후 정산:** 입력한 **1인 회비**를 그대로 걷고, 입금 확인한 금액을 실제 부담액에서 뺍니다. 여유분이나 천 원 단위 올림은 적용하지 않으며, 총 모이는 금액은 1인 회비 × 인원입니다. 이미 입금 확인한 회비는 당시 금액을 유지합니다.

두 방식 모두 차수별 참석자 변경과 노술 계산을 지원합니다. 방식과 입력 내용은 자동 저장됩니다. 입금 확인한 회비가 있는 상태에서 바로 정산 탭을 누르면 페이지 안에 확인창이 나옵니다. **취소**하면 기록과 방식을 유지하고, **바꾸기**를 누르면 모든 차수의 입금 확인만 해제해 바로 정산으로 전환합니다. 닉네임·인원·계산서 금액·노술 입력·정산 완료 상태는 유지하며, 전환 후에는 선입금을 차감하지 않습니다.

바로 정산은 이름과 보낼 금액을, 선입금 정산은 추가 입금·환불·정산 없음을 표시합니다. 보낼 금액과 방향이 모두 같으면 단톡 문구를 한 줄로 묶고 대상자 닉네임을 괄호 안에 함께 표시합니다. 이번 정산 차수 중 노술로 선택한 사람은 단톡 문구의 닉네임 뒤에 `(노술)`을 붙입니다. 노술계산을 끄거나 해당 차수가 정산 완료된 경우에는 이 표기를 적용하지 않습니다.

안내 대상이 한 명이면 `sample1 1인 20,500원 보내주세요.`처럼 닉네임을 표시하고 “모두”는 붙이지 않습니다. 선입금 방식에서도 한 명 안내에는 같은 원칙을 적용합니다.

금액 칸에 붙여 넣은 쉼표와 공백은 자동으로 제거하며, 입력 칸 아래에 `82,000원`처럼 표시합니다. 금액은 **10자리 이하**로 입력하며, 초과 입력하면 이전 금액을 유지하고 안내를 표시합니다. 닉네임 입력 전에는 정산 칸에 입력한 참석 인원과 **닉네임 입력 전** 안내가 나옵니다. 닉네임은 모두 입력해야 계산할 수 있습니다.

참석자는 고유 ID로 연결합니다. 1차 닉네임을 수정하면 같은 사람의 이후 차수 참석·노술 선택·입금 기록·결제자 지정에도 새 이름을 반영합니다. 기존에 저장한 모임은 처음 불러올 때 자동으로 변환합니다. 서로 다른 사람에게 같은 닉네임을 입력하면 계산 전에 수정 안내를 표시합니다.

사람별 상세의 차수별 금액은 각 차수에서 따로 원 단위 반올림하여 같은 조건의 참석자는 같은 금액으로 표시합니다. 최종 부담액은 기존처럼 반올림 전 금액을 합산해 100원 단위로 올림합니다. 차수별 표시 합계와 최종 부담액의 차이는 상세에 함께 표시합니다.

두 방식 모두 **결제한 사람 (선택)**을 지정할 수 있으며, 선택하지 않아도 계산할 수 있습니다. 선택한 사람의 부담액은 그대로 계산하고, 화면과 단톡 문구에 **닉네임 5,500원 (결제함)**처럼 표시합니다. 결제자는 본인에게 보낼 돈이나 돌려받을 돈을 안내하는 대상에서 제외하며 다른 사람의 정산액은 바뀌지 않습니다. 같은 금액 요약의 인원수에서도 결제자를 제외하고 결제자 내역은 따로 표시합니다. 선택한 사람이 이번 정산 명단에서 빠지면 선택이 해제됩니다.

각 차수의 **정산 완료**를 체크하면 해당 차수의 계산서와 받은 회비를 이후 계산에서 함께 제외합니다. 완료 당시 닉네임·참석자·노술 선택·계산서 금액도 고정하므로 다른 차수를 수정해도 바뀌지 않습니다. 1~4차를 각각 표시할 수 있으며, 모두 완료하면 추가 청구 문구를 만들지 않습니다. 내역은 보관하고 새로고침 후에도 완료 상태를 유지하며, 체크를 풀면 다시 계산에 포함합니다. 실제 입금·환불까지 마친 차수에만 체크해 주세요.

선택한 계산 범위 밖의 미확인 선입금 초안은 현재 계산을 막지 않습니다. 해당 차수까지 계산하려면 실제 입금 확인을 마치거나 초안을 정리해 주세요.

캡처에서는 닉네임 앞의 둥근 자기 표시를 제거한 뒤 글자를 읽습니다. 기존 참석자 명단과 달라지면 **캡처 이름 확인**에서 오타와 빠질 사람을 확인하고 **명단 적용**을 눌러 주세요. 확인 전에는 기존 선택과 정산 기록을 바꾸지 않습니다.

`index.html`은 가벼운 계산기 화면입니다. 캡처 사진을 선택하면 같은 사이트의 `assets/ocr-worker-v1.js`를 불러와 닉네임을 인식합니다.

캡처 인식은 배포된 HTTPS 주소 또는 로컬 웹 서버에서 사용할 수 있습니다. HTML 파일을 직접 열었을 때는 닉네임을 직접 입력해 주세요. 배포할 때는 `assets` 폴더와 `THIRD_PARTY_NOTICES.txt`도 함께 올려야 합니다.

- 입력한 명단·계좌·금액은 현재 브라우저에 자동 저장됩니다.
- 화면 위 **초기화** 버튼을 누르면 페이지 안 확인창이 열립니다. **취소**하면 입력을 유지하고, **초기화하기**를 누르면 저장된 명단·금액·입금 확인·계좌를 지우고 새 모임으로 시작합니다.
- 휴대폰이나 브라우저가 바뀌면 저장 내용이 이어지지 않습니다.
- 캡처는 기기 안에서 처리하며 서버로 전송하지 않습니다.
- **전원 입금 확인**은 사용자가 실제 입금을 확인한 뒤 체크하는 기능입니다.
- 정산액은 100원 단위로 올림합니다. 올림 차액은 정산 담당자에게 남기는 방식입니다.
