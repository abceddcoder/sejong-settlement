# 모임 금액정산 계산기

모임에서 회비를 먼저 걷고, 차수별 참석자와 술값을 반영해 마지막 차액을 정산하는 계산기입니다.

`index.html` 하나에 화면과 캡처의 닉네임 인식 기능이 포함되어 있습니다. 브라우저에서 열어 사용할 수 있습니다.

- 입력한 명단·계좌·금액은 현재 브라우저에 자동 저장됩니다.
- 화면 위 **초기화** 버튼으로 저장된 입력을 지울 수 있습니다.
- 휴대폰이나 브라우저가 바뀌면 저장 내용이 이어지지 않습니다.
- 캡처는 기기 안에서 처리하며 서버로 전송하지 않습니다.
- **전원 입금 확인**은 사용자가 실제 입금을 확인한 뒤 체크하는 기능입니다.
- 정산액은 100원 단위로 올림합니다. 올림 차액은 정산 담당자에게 남기는 방식입니다.

안드로이드·아이폰 실기기에서의 캡처 인식 검증은 아직 완료되지 않았습니다.
